## Panel 页怎么读

| 功能区 | 主要器件与路径 | 可以直接看清的关系 |
| --- | --- | --- |
| 1：屏幕连接器 | FPC1、C7、C10、C11 | 电源引脚、内部 VCC/VCC1配对、VCOM输出旁路及供电控制／采样信号 |
| 2：SPI模式与默认状态 | R24/R25、R1、R35/R36 | BS0/BS1到VDD的0Ω绑带，BUSY到VDDIO的上拉，未用SI2/SI3的下拉 |
| 3：温度传感器 | U4、R20/R21、R22/R23、C27 | FPC的TSCL/TSDA直接连到U4，两个总线上拉，地址脚和GND接地，供电去耦；R23保持DNP |
| 4：源极电源配对与电容 | C1–C6、C103–C120；附近的C8/C9 | 六组输出／输入引脚的配对，以及各组三只10µF加一只3.3µF并联；公共电极输出的独立旁路 |

FPC1仍是单个60针连接器实例。为便于阅读，其符号按功能安排左右两侧引脚；**图中的位置不代表实物针脚顺序、接触面或插入方向**，实物编号由旁边保留的引脚数字及原厂封装图确定。11/15/40/57脚保留明确的NC标记，其中40脚仍为采用方案中未连接的DRVN2。

C1–C6各组名义容量33.3µF，图中的并联关系不代表有效容量／环路已验收。源极电源六组分别为VSPH、VSPL、VSPL2、VSNH、VSNL、VSNL2，不允许因画成相似结构就把它们合并。

## Interface 页怎么读

| 功能区 | 主要器件与路径 | 可以直接看清的关系 |
| --- | --- | --- |
| 1：外部主控连接器 | J2 | 信号脚与共地脚，Pin16的HOST_3V3只供主控侧逻辑 |
| 2：主控到屏幕 | U6、R39–R43、R44–R48、Q9/R37、C34 | 五路输入经缓冲通道和33Ω串联电阻送屏幕；时钟／数据／复位默认低，片选默认高；Q9控制两个低有效OE |
| 3：屏幕到主控 | U7、Q10/R38、C35 | BUSY和SI1分别缓冲为HOST_BUSY_N和HOST_MISO，未用输入接地、输出NC；Q10控制两个OE |
| 4：电源测试点 | TP1–TP12 | 输入、逻辑、正负模拟／栅极／偏置等电源测试位置 |
| 5：控制与地测试点 | TP13–TP24 | BUSY、供电使能、复位以及共地测量焊盘 |

U6/U7仍各为一个SN74LVC244A实例，图中展开全部8个缓冲通道，用三角形表示信号流向，保留实际物理管脚编号。1OE_N控制第一组四路，2OE_N控制第二组四路；两个OE在本项目各自连到同一个使能网络。它们只是使能缓冲通道，不产生电源。

`EPD_PWR_EN`为高时，Q9/Q10导通把各自OE拉低，允许通信；为低时，R37/R38把OE上拉到各自供电域，使输出高阻。U6由EPD_3V3供电，U7由HOST_3V3供电，不能把两个域看成同一个物理电源入口。动态上下电验收仍见[接口状态约定](interface-power-state.md)。

**测试点的红叉不是NC。** TP1–TP24原工程标为DNP且不计入BOM，表示无需装配独立器件；其铜测试焊盘仍在PCB上，电气连接已经保留。真正NC是未连接管脚端点的小叉。R23的DNP则表示该电阻不装，不能把ALERT直接接地。

## 图形和标签约定

区内主要路径用正交导线连接。圆点表示连接，无圆点的交叉线不连接；连接器配对、电容并联、上下拉和使能电路都已展开。电阻、电容、NMOS取自本机KiCad官方符号图形；连接器、传感器及缓冲器按实际管脚定制图形并存入项目库。

全局标签用于跨页或跨功能区接口，以及保留已经布线的PCB网络名称。部分内部网络也保留一个名称标记，以免产生新的自动网络名。相比给每个器件脚贴一个标签，本次把局部回路实际接在一起；不会画贯穿三个页面的长线。

两页采用与电源页相同的594×450mm自定义图幅；这是原理图纸张大小，PCB仍为100×80mm。
