# 当前 release 产物核对

2026-10-03，KiCad 10.0.6。核对对象：`releases/cad-review-2026-10-01/`。

结论：现有制造文件与当前原理图和 PCB 一致，不需要重新发布制造数据。已补充当前源文件和产物的哈希清单，保留原制造文件。

## 方法和结果

从当前原生 PCB 重新导出到临时目录，与现有 release 比较；重新导出顶层原理图网表，读取原理图属性与 PCB 实体封装字段进行交叉核对。

| 产物 | 本次核对 |
|---|---|
| 9 层 Gerber | 全部相同，仅去除生成时间字段；铜线、覆铜、焊盘、文字及其他数据保持比较 |
| PTH、NPTH 钻孔 | 全部相同，仅去除生成时间字段 |
| Gerber Job | 除生成时间外，层清单、规格与叠层等内容一致 |
| 两份钻孔图 PDF | 逐页渲染像素相同 |
| KiCad 坐标 | 127 项，CSV 内容完全一致 |
| 嘉立创 CPL | 127 项，与当前坐标转换结果完全一致 |
| BOM | 43 组、129 个器件；逐位号检查数值、封装、厂商、料号与数量，一致 |
| Gerber ZIP | 成员清单完整，每个成员字节与 release 对应文件一致 |

测试焊盘 TP1–TP24 的“排除坐标”标志在原理图和 PCB 中不同，但它们均为 DNP，并排除 BOM。本工程导出坐标时启用了排除 DNP，因此它们在实际 BOM 与 CPL 中都正确排除，无需为此改变 PCB。它们的实体铜焊盘仍在 Gerber 中。

当前原理图与 PCB 的检查结果：ERC 0；保存铜层 DRC 0、未连接 0、原理图一致性问题 0；398 个固定连接引脚校验通过。没有忽略规则或 DRC 排除。

旧检查记录的 `.kicad_pro` 哈希与当前文件不同；原理图、PCB 等其他已记录源文件哈希未变。本次重新检查当前配置后刷新记录，没有修改原生设计。文件哈希变化本身不能证明工程配置具体改了什么，因此没有将其归因于某项编辑操作。
