# v0.9 手工焊接说明

按本版BOM采购104个装配件，顶面102个SMT，J1/J2为2个直插。TP1–TP26是板上的裸铜测试点，不是要购买焊接的器件。所有极性和位号以本版装配图、原理图和PCB为准。

1. 用温控焊台、细焊锡、助焊剂、镊子、吸锡带、放大镜/显微镜；1210大电容不要用烙铁长时间加热同一端，宜预热后短时焊接。FPC 0.5mm间距、SOT-323和采样1206仍需精细操作。
2. 先焊电阻及小电容，再焊IC、晶体管、二极管、功率电感和大电容，最后焊FPC与直插排针。0805手焊焊盘较长，先少量上锡一端、定位，再焊另一端。不要桥连SOT-323的1/2脚。
3. R17与R50均为200kΩ，必须两只齐焊，不能只焊一只。R49为0Ω调试支路，正常闭合；隔离GDRC测量时须断电后操作，重新上电前确认Q7栅极状态，不能随意留空运行。
4. BAT54S是串联双二极管；D1/D2/D4阴极及MOS脚序不可凭封装大小推断。Q7为PJA3433，不能当成N沟MOS替换。FPC锁扣插拔先断电，确认屏幕接点朝向及1脚。
5. 不接屏幕，先用万用表检查BENCH_3V3/EPD_3V3对地短路和所有电源极性；用限流3.3V供电检查U5开关及主机默认状态。后续按屏幕时序测试带负载电压/纹波、采样电阻波形、MOS/电感温升、显示刷新和安全掉电。

钢网是可选工具，手焊不必订购；如用热板/锡膏，应使用本版F.Paste生产文件。电阻扩大封装不代表屏幕高压供电已完成实测，本版不提供实板性能签核。

本轮只换三组电阻（R7、R10/R19、R17/R50），全部沿用0805焊盘；阻值与数量保持。R10/R19装2.2Ω±1% C17521；R17/R50各200kΩ±1%、100ppm/℃ C17539；R7为4.3kΩ±1% C17667。R17/R50不允许漏焊。其他器件仍按v0.8型号，102件SMT全部在机器BOM及CPL中，只有J1/J2在人工BOM；你如选择完全手焊，可使用完整BOM和装配图。Q7国内缺货仍需先解决来源，不临时换成未经审核的PMOS。
