# v0.4外部主控接口与电源状态约定

2026-10-07。这是删除硬件隔离后必须由固件和接线遵守的约束。本轮交付硬件及约定，不交付固件。旧版U6/U7隔离接法已停用。

## 接线边界

只允许3.3V逻辑、稳压3.3V屏幕供电和共地。J1.1为正、J1.2为地；本板没有5V转3.3V稳压器。J2.16为NC，留空；不得继续连接原HOST_3V3。J2.5为SI1输入、J2.13为BUSY_N输入；其余定义见[引脚表](host-interface.csv)。排线建议不超过10cm，禁止热插拔。

主控先上电、最后断电。屏幕有电时，主控必须保持供电有效，避免BUSY/SI1反灌已掉电的主控。反过来，屏幕无电时不能通过GPIO给屏幕注入高电平。33Ω电阻和100k拉电阻不提供掉电隔离。

## 无屏幕电源时

EPD_PWR_EN保持低；HOST_SCLK、HOST_MOSI、HOST_CS_M_N、HOST_CS_S_N、HOST_RES_N均输出低。BUSY与SI1配置输入并关闭内部上拉，上述输出也不得启用内部上拉。可使用确定无上拉的高阻输入替代输出低，但必须确认MCU启动/复位默认状态和外接电路；基线按输出低执行。

此时两个片选低并非工作中的“选中事务”：屏幕无电、RESET为低。不能为保留片选高而向断电屏幕输出高电平。默认拉电阻不能覆盖错误的推挽高输出。

## 上电步骤

1. 主控先就绪：EN=0，所有输出低，BUSY/SI1为无上拉输入，SPI外设尚未驱动。
2. 连接J1稳压3.3V，在输入侧有效且屏幕域关闭状态下拉高EPD_PWR_EN。
3. 等待VIN、EPD_3V3、AVDD稳定。C36=1nF是毫秒级软启动设计，具体等待时间必须由带载波形确认；初次调试可先保守等待10ms并测量，不把10ms视为已验收的额定时间。
4. 在RESET仍低、SPI仍停止时将两个片选设高，保持SCLK/MOSI低。
5. 按匹配屏幕规格进行复位、初始化及电源命令；只在供电有效时使用BUSY同步和SPI。不能在启动供电瞬间发送事务。

## 正常关机步骤

1. 停止新刷新，按屏幕协议完成当前刷新并检查BUSY状态。
2. 执行已采用的POF(02,00)，有界等待BUSY置忙/释放；超时进入错误处理，不继续假定关机成功。
3. 执行深睡(07,A5)，保持面板规格要求的间隔（采用方案要求>10µs，原型起点1ms）。命令格式必须与选定Standard SPI及具体屏幕资料匹配。
4. 停SPI，禁止其重新接管引脚；将时钟、写数据、两个片选、RESET全部输出低，BUSY/SI1保持无上拉输入。
5. 最后将EPD_PWR_EN置低。U5 QOD释放直接连接的低压输出电容，不能由此认定高压轨已清空。
6. 需要断开主控电源时，在屏幕关机及残压条件实测确认后再断主控。

## 异常条件与验收

主控复位、断电、程序崩溃和排线插拔仍可能中断刷新或引发反灌，电路没有提供异常安全掉电保证。若应用必须独立容忍这些条件，需要恢复硬件隔离或另行设计；当前以用户接受的软件约束为边界。

首板至少测量上电浪涌、供电稳定时间、关屏GPIO电平、BUSY/SI1反灌、全部高压轨关断及残压。关机命令、时间和状态边界沿用[屏幕采用方案](../../../../docs/design/pcb.md)，不以ERC/DRC代替波形与屏幕实测。
