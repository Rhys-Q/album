# FPC 封装尺寸核对

2026-10-01，从已记录的立创托管 Xunpu 原厂 PDF 下载原始文件。`sources/xunpu-fpc-original.pdf` 为原始字节；其交叉引用偏移有异常，MuPDF不能直接读取。`sources/xunpu-fpc-recovered.pdf` 是在内存中令解析器重建交叉引用后另存的可阅读副本，不覆盖原始文件。已实际查看第一页 Rev A 机械图和推荐焊盘图；系列表含 FPC-05FB-60PH20，不把图上30针示意或8针标注当成60针的定长尺寸。

尺寸以图纸的 N=60 公式计算：信号间距0.5mm，焊盘0.30×1.20mm，第一到最后焊盘中心距29.5mm；固定脚焊盘2.0×1.8mm，左右中心距32.6mm；固定脚中心相对信号焊盘中心行向后3.25mm。塑胶主体宽33.5mm；主体深4.9mm，含端子总深5.4mm，标称高度2.0±0.1mm。推荐FPC厚0.30±0.02mm。

项目坐标：60个信号焊盘中心y=2.5mm；固定焊盘中心(x,y)=(±16.3,5.75)mm。固定脚没有电气网络。边界还留装配裕量。

Pin1在工程顶视图左侧，数字递增向右；实际连接器、屏幕FPC的接触面、Pin1和插入方向仍需以样件/原厂明确的板侧顶视图核对。图中的FFC焊指观察面不能自动视为PCB顶视面。机械尺寸核对完成不等于已经完成接屏兼容性测试。禁止带电插拔。
