# P4 GDRC 调试断点：v0.5

2026-10-07，KiCad 10.0.6。在原有 P4 负偏置供电支路增加 R49、TP25、TP26，Q7 仍为参考图的 PJA3433 PMOS。本改动提供测量和隔离位置，不表示 GDRC 驱动匹配疑问已经通过实测解决。

```text
屏幕 GDRC ── TP25 ── R49（0Ω，0805）── TP26 ── Q7.G
                                      │          Q7.S = RESEC
EPD_3V3 ───────────── R13（1MΩ）────────┘          Q7.D = SW_VCOM
```

R49.1 为 GDRC，R49.2 为新增网络 Q7_GATE；Q7.1 与 R13.2 均接 Q7_GATE。R13 留在 MOS 栅极侧，断开 R49 后仍为栅极提供弱上拉，使其在源极接近 EPD_3V3 时趋于关闭，避免失去原来的默认状态。1MΩ 是弱偏置，不是栅极钳位或可靠的主动保护。

| 位号 | 规格/采购 | 作用及装配 |
|---|---|---|
| R49 | 0Ω，0805；Yageo RC0805JR-070RL | 正常工作必须装上，提供可拆断点；若永久取消电阻，必须用铜线或可靠桥接保持连通，不能空焊 |
| TP25 | 顶面铜焊盘，网络 GDRC | 测控制器侧输出；DNP，不采购、不焊接元件 |
| TP26 | 顶面铜焊盘，网络 Q7_GATE | 测 MOS 栅极侧；DNP，不采购、不焊接元件 |
| R13 | 原有 1MΩ | 保留在栅极侧，原值、源端供电和默认关断意图不变 |

正常装配时 0Ω 电阻有小的实际电阻和寄生电感，两个测试点电压应基本相同。它不是电平转换器、反相器或 MOS 型号转换器，也不会自动解决规格书 NMOS 描述与参考 PMOS 的差异。只有波形证明需要调整时，才评估将 R49 换成有限阻值的栅极电阻；没有在本次改版中指定替代阻值。

调试时先保留 R49，对比 TP25/TP26 的高低电平、频率和占空比，并测 Q7 源极 RESEC，关注实际 VGS = V(Q7_GATE) − V(RESEC)。不能只看 GDRC 对地电压或占空比判断 PMOS 是否匹配。检查启动、刷新、控制释放及掉电阶段，同时观察 SW_VCOM 和负偏置输出。

需要隔离时必须断电、确认储能已释放，再拆 R49。拆开后 TP25 可观察控制器空载输出，TP26 可观察 R13 偏置状态，但空载波形不能证明带 MOS 栅极电容时仍正常。任何外部栅极驱动实验都应先断开 R49，不能与屏幕控制器输出直接对顶；实验方案还须满足 Q7 栅源额定值与上下电约束。普通接地示波器地夹只接 GND；测栅源差分用合适的差分测量，不能把地夹接 RESEC。

PCB 已在 Q7/R13 附近放置 0805 R49 和两个顶面测试点，完成补线和原生重新铺铜。原理图、PCB、设计记录及本地封装/模型同步；ERC 0，完整 DRC 0、未连接 0、原理图一致性问题 0；已在 KiCad GUI 实际打开核对。Q7 的源漏、采样电阻及负偏置功率回路保持原接法。

本版为 103 个装配件（101 个顶面 SMT＋J1/J2），26 个铜测试点，129 个原理图实体，133 个 PCB 封装（含 4 个安装孔），317 个连接引脚。新制造审阅包为 [v0.5](../releases/jlc-cn-review-v0.5-2026-10-07/README.md)，旧 v0.4 文件保留为历史快照。本次改版前原生文件见 `reports/gdrc-debug-v0.5/before/`。
