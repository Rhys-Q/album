# 用v0.5手焊版学习KiCad

2026-10-07，KiCad10.0.6。当前103个装配件，129个原理图实体（包括26个DNP铜测试点）。建议先阅读，再复制完整工程练习；正式工程仍作为真源。

## 第一课：工程、原理图与PCB

打开`gdep133c02-driver.kicad_pro`，从工程管理器进入原理图及PCB编辑器。`.kicad_pro`保存设置，`.kicad_sch`定义连接，`.kicad_pcb`定义实体焊盘、位置、走线、铜层和板框。相同基本文件名方便KiCad匹配，但真正的元件关联还依赖符号UUID路径；改名字或手工新建一个同位号封装不一定能保留对应关系。

顶层原理图只有三个分层入口：power是输入与正负电源，panel是FPC及温度、电容，interface是主机直连及测试点。跨页全局标签连接同名网络，局部线路已展开成可读电路。参考[KiCad官方入门](https://docs.kicad.org/10.0/en/getting_started_in_kicad/getting_started_in_kicad.html)。

练习：分别找到J1、J2、U5、FPC1。答案：J1接稳压3.3V台式电源，J2接3.3V主控，U5控制供电，FPC1是可插屏幕软排线的连接器底座。U6/U7在本版已删除。

## 第二课：器件、引脚与网络

位号标识某个元件，Value说明规格，MPN说明完整购买型号，Footprint决定焊盘形状。U1/U2/U3虽然用U位号，实际是0.2Ω采样电阻；L4/L5已删除，L1–L3是15µH功率电感。

网络是所有应接通的电气节点集合。U5.3、R30.1、J2.15同属EPD_PWR_EN；R30.2为GND。NC表示某个引脚故意不接，DNP表示元件故意不装：U4.3与J2.16为NC，TP1–24为DNP铜焊盘，后者仍存在于PCB铜层。

练习：查U5六脚。答案：1=BENCH_3V3、2=GND、3=EPD_PWR_EN、4=SW_CT、5/6=EPD_3V3。芯片1脚的功能名称VIN表示输入；实际输入网络为BENCH_3V3。

## 第三课：沿能量路径读电源

`J1 → BENCH_3V3 → U5 → EPD_3V3`，输出直接分为逻辑和功率铜线支路，共用同一电气网络。C36接CT与芯片输入，控制U5斜率；100k R30使ON默认低。

之后看L1/Q1/D1正升压、L2/Q8/D2反相、L3/Q7/D4负偏置，再看正负电荷泵。屏幕内部控制器提供GDR/DRV和反馈控制，MCU通过SPI发指令。详见[电源逐项讲解](power-circuit-explained.md)。

练习：为什么不能删掉U1或把50V电容都换成6.3V？答案：U1参与电流采样，删掉会破坏控制；电容耐压由所在轨电压决定，输入3.3V不代表高压输出也是3.3V。当前六组33.3µF并联组合仍须核对偏压下有效容量。

## 第四课：符号怎样对应封装

在原理图选中U5，按E查看Footprint字段，它指向本地`Driver:Package_TO_SOT_SMD__SOT-23-6`。PCB中同一器件使用该封装；符号引脚编号对应封装焊盘编号，而非屏幕上看起来的左右位置。

本地库表`sym-lib-table`、`fp-lib-table`负责解析库名；`lib/`保存实际定义。3D模型帮助外形查看，不能代替焊盘尺寸及配接验证。当前STEP是旧版历史产物，不能用它核对当前v0.5。

练习：核对FPC1的60个信号焊盘及固定焊盘，确认0.5mm间距。答案：底座的焊脚焊在PCB上，屏幕排线插进底座；PCB图显示焊盘并不表示要把屏幕排线直接焊上去。

## 第五课：从原理图更新PCB

在副本中修改一个低风险字段，先运行ERC；切换PCB编辑器，用“从原理图更新PCB”（通常F8）。检查更新列表中的增加、删除、封装和值变化，再执行更新。新元件通常出现在未摆放区域，连接显示为飞线；KiCad不会因为完成更新而自动做好布局和布线。

保留对应关系时，元件位置和已有走线通常保留；删除0Ω或换封装则可能留下走线短路、悬空或断连。因此更新后要重新布局、走线、按B铺铜并运行DRC，包括原理图一致性检查。不要将飞线当成已存在的铜线。

练习：在副本更换一个电阻的封装，观察F8后的变化，再撤销。答案：电气网络可能不变，但焊盘尺寸改变会影响间距和已有铜线，仍需DRC。不要在正式文件中保存练习。

## 第六课：看铜层与检查结果

本板F.Cu/In1.Cu/In2.Cu/B.Cu四层；In1为地平面，元件全部顶面，底面有铜线和铺铜。“双面有铜”与“双面贴装”是不同概念。边界是Edge.Cuts，阻焊是Mask，可选钢网用Paste。

当前ERC0、DRC0、未连接0、一致性问题0，317个连接引脚与PCB逐脚对应，原生API重新铺铜完成。当前KiCad GUI实际打开已通过；CAD检查不代替硬件测试。波形、温升、有效容量、屏幕及FPC配接仍待验证。

练习：找到U5附近C36，确认其两个焊盘分别BENCH_3V3和SW_CT，不能有地连接。查看J2.16确认NC，查看BUSY线路确认没有U7。

## 第七课：制造文件、采购与上电

使用`releases/jlc-cn-review-v0.5-2026-10-07/`。Gerber ZIP是制板数据；bom-all是完整103个采购清单；bom-smt是101个SMT清单；bom-manual是J1/J2；cpl-smt是101个位置；positions-kicad为原始核对坐标。BOM列出买什么，CPL列出装在哪里，不能互换。

手焊下单可只做裸PCB，是否买钢网取决于使用锡膏回流还是烙铁。FPC、SOT-323和0603仍需放大观察、助焊剂、细焊锡、吸锡带及控温烙铁。焊后先断电查短路，再用限流3.3V分阶段检查；高压电源和屏幕接入需要按测量计划操作。

最关键的软件练习：读[上下电约定](interface-power-state.md)，说明关屏为何不能保持片选高。答案：硬件隔离已移除，高电平可能通过屏幕输入反灌；正常关机命令完成后停SPI、全部输出低，再关U5。主控先上电最后断电，BUSY/SI1输入无上拉，禁止热插拔。

学习通过标准：能从任一符号找到正确PCB焊盘，解释电源与信号路径，识别一次修改需要F8/重新布线/DRC，并选择同一版本的Gerber、BOM、CPL。生产审阅包不等于已完成实测的产品。
