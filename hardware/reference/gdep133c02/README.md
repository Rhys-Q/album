## 已取得的电路依据

- `EPD_VDD` → U5 → `VIN`；`VIN` 分成逻辑供电（L4 → EPD_3.3V → VDD/VDDIO）和模拟供电（L5/R31/C31/C32/R32 → AVDD）。电路本身没有输入稳压器；本项目选择前级稳压 3.3V，不能从 AA 原电池或 USB 5V 直接接入。
- 外置正/负压、电荷泵和 TFT_VCOM 使用面板控制/反馈脚与分立 MOS、BJT、二极管、电感；图中没有额外独立的专用升压控制 IC。本项目使用现有初始化与面板内置VCOM（规格书p12）；OTP/波形与温度命令按到货及最小显示结果验证。
- U4 TCN75A 与其 TSCL/TSDA 上拉均在 EPD_3.3V 域；A0–A2 接地。不能把它改为常供电，或直接当成 MCU I²C 外设。
- BUSY 通过 R1=2kΩ 上拉到 VDDIO。Pin12/18 为相连的内部 VCC；Pin13/14、16/17 分别为 VDDP/VDDN；六组源极输出/输入对分别相连。NC11/15/57 保持不接。连接器61/62为固定焊脚，不是面板信号61/62。
- 参考电容没有完整耐压、介质、有效容量或封装信息；15uH 电感没有 Isat/DCR。所有关键器件必须完成实际料号选型和布局审核。
