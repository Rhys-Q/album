## 2. 已完成的兼容处理

1. 从当前 PCB 重新导出 Gerber，禁用 X2 和网络属性；制板 ZIP 只包含 9 份 Gerber 和 2 份钻孔文件。国内官网列明接受 RS-274-X、不支持 X2，故采用这一兼容格式。[官方文件类型说明](https://www.jlc.com/portal/2/serviceGuide)
2. 完整 BOM 共 102 个装配器件；将 J1、J2 拆出后，SMT BOM 与 CPL 的位号集合完全相同，共 100 个，无重复位号，分组数量与位号个数相符。
3. BOM 封装改用常见名称，例如 `0603`、`1206`、`SOIC-8`、`SOT-23-6`。尺寸名称使用英制；例如 0603 对应约 1.6×0.8 mm。定制 FPC 和电感保留针数／间距或系列名称，完整厂商与 MPN 仍保留。
4. Comment 中保留原规格并加入完整 MPN，便于选型；没有臆造嘉立创物料编号，也没有替换器件。
5. CPL 的 X、Y、角度均为纯数字；板面采用 `T`，整份文件的坐标单位统一为毫米。没有平移原点、镜像坐标或修改旋转。

导入时应将 `Comment`、`Designator`、`Footprint`、`Quantity` 等列映射到对应字段；额外的 `MPN` 是完整型号的重要核对依据。若平台只按 Comment/封装匹配，也必须核对完整 MPN。[官方 BOM／坐标规范](https://www.jlc.com/portal/server_guide_48022.html)

## 3. PCB 订单怎样填写

进入 [嘉立创国内站](https://www.jlc.com/) 的 PCB 计价／下单，上传本次 RS-274-X ZIP，检查预览识别到四层板和完整钻孔。

| 参数 | 本工程的数据或建议 |
|---|---|
| 材料 | FR-4 |
| 铜层数量 | 4 层 |
| 单板尺寸 | 100×80 mm，按板框中心线定义 |
| 板厚 | 1.6 mm |
| 层顺序 | F.Cu → In1.Cu → In2.Cu → B.Cu |
| 外层铜厚 | 工程审阅条件为 1 oz |
| 内层铜厚、介质叠层 | 与工厂确认；不能把默认选择当作已完成温升验收 |
| 阻焊／丝印颜色 | 按个人偏好选择；普通绿色便于观察 |
| 表面处理 | 首次样板建议考虑沉金，结合报价与工厂建议决定 |
| 数量 | 首次小批量样板；按平台当前最小数量和报价选择 |
| SMT | 自己手焊选择不需要；如委托贴片则仅顶面 |
| 确认生产稿 | 需要 |
| 盲埋孔、金手指、阻抗控制 | 本工程未设计这些专项要求，不要自行添加 |

某些查看器按板框线宽的外沿显示约 100.05×80.05 mm，需确认实际加工外形仍按本工程 100×80 mm 板框理解；不要为凑显示尺寸缩放图形。

若平台要求工艺边、拼板或定位标记，让工程人员给出方案，并核对更新后的生产稿与 SMT 对应关系。当前文件是单板，不是已经设计好的拼板；不要自行修改一份 CPL 来适配另一份 Gerber。进入 SMT 的具体按钮以平台实际界面为准。[官方拼板与 SMT 流程](https://www.jlc.com/portal/server_guide_51463.html)

自己手焊时订单备注写“仅裸板，不做SMT”；钢网按焊接方法自行选择，烙铁焊接不必购买，锡膏回流可选顶面钢网层（stencil-optional/F_Paste.gtp）。底面没有待贴元件。

如改为SMT，建议在订单平台正式备注入口明确：

```text
四层单板，板框中心线尺寸100×80mm，厚1.6mm。
顶面SMT装配，待贴位号以本次SMT BOM和CPL为准，共100个。
J1、J2不在本单SMT范围，收到后手工焊接。
请提供PCB生产稿与装配预览供确认；物料替代请先明确完整型号及封装。
```

这段备注不替代平台的工艺参数选择。拼板数量、贴片数量应结合实际订单填写，不能照抄尚未决定的数量。

## 4. SMT 器件匹配怎样检查

上传本次 SMT BOM 和 CPL 后，先确认系统解析出 100 个待贴位号。全部在顶面，因此本次选择顶面贴装。

当前未绑定嘉立创 SMT 物料编号，需在平台上逐项匹配。不能看到“匹配成功”就跳过型号检查；在需要人工关联时，根据完整 MPN 搜索，再核对厂商、封装和关键参数。立创商城有货也不等于 SMT 库有货。

| 对象 | 重点核对 |
|---|---|
| FPC1 | `FPC-05FB-60PH20`；60 针、0.5 mm 间距，安装的是插排线底座 |
| U1、U2、U3 | 实际为 `WSL1206R2000FEA` 0.2 Ω 电流采样电阻，不能按 IC 处理 |
| U5 | `TPS22917DBVR`，SOT-23-6；不要混购低有效TPS22917L |
| C36 | `C0805C102J5GACTU`，1nF/50V、C0G、0805、±5%；不是1µF |
| U4 | `TCN75AVOA713`，SOIC-8 |
| 高压电容 | 核对完整 MPN、容量、耐压与封装；相同标称容量不证明有效容量相同 |
| L1～L3、MOS 管、二极管 | 电感系列、管脚排列、极性与电气额定值不能仅凭外形相近替换 |

遇到无货：先确定是等待备料、工厂接受的自备料途径，还是需要重新选型。更换关键器件后，重新审核设计和制造文件，不要直接接受“同封装替代”。完整 BOM 内的两个手工排针另外采购：J1 为 `TSW-102-07-G-S`，J2 为 `TSW-108-07-G-D`。

## 5. 装配预览与生产稿怎样看

预览阶段逐项检查：

- 待贴器件数为 100；FPC1 在贴装清单中，底座应由工厂焊接。
- J1、J2 不参与本次 SMT；R23已删除，TP1～TP24不在待贴清单。测试焊盘的铜仍留在 PCB 上。
- FPC1 插入口、Pin 1 与实物屏幕排线相符；排线本身后续插入底座，不焊接到板上。
- 芯片 Pin 1、二极管极性、三极管／MOS 管方向正确；不要只检查文字朝向。
- 所有元件位置与焊盘对齐，旋转正确。CPL 中 Y 坐标为负值是当前 KiCad 导出惯例，不要自行取绝对值或把全板移动到第一象限。
- 四层铜层顺序、板框和四个 Ø3.2 mm 非金属化安装孔正确；没有意外增加或丢失内层。

如导入后全部器件整体错位，先检查平台原点映射，不要随意改一两列坐标。平台若要求转换，必须保存转换依据并用全板预览验证。
