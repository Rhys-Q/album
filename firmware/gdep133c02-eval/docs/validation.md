# 验证记录

目标：自制驱动板 v0.11 + 微雪 ESP32-S3-DEV-KIT-N8R8。
工具版本采用用户本机 ESP-IDF v6.1，提交 `fff9895c82d744c7237be8847347bdd1b07c6643`。最终结果和产物哈希见软件 release 的 `verification.json`。

## 软件检查

- 干净构建：以独立 `build/idf6.1` 目录构建，不沿用5.5.1或厂家build。
- C测试：EPF精确长度、字段、保留字、CRC、非法索引；六色色码、旋转和主从拼接；完整事务中每个SPI调用失败点；BUSY一直高、一直低及命令期间短忙脉冲；故障锁存；正常POF/深睡顺序。
- Python测试：打包、非法输入、等比留白、透明背景白底。
- 代码检查不替代示波器测量；不自动连接、烧录用户硬件。
